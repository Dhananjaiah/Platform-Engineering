## How to use
1. Do the lab (typing every command). 2. Read the module's `interview.md` and answer **out loud** before reading the model answer. 3. Re-answer with a stopwatch: 2 minutes per scenario. 4. Record yourself once per module and listen for filler and missing trade-offs.

## Answer framework for scenarios (use every time)
**Clarify** (scale, constraints, what changed) -> **Diagnose/Design** (method, commands, options) -> **Decide** (recommendation with trade-offs) -> **Mitigate and prevent** (guardrails, automation, metrics) -> **Communicate** (who needs to know, in what words). For design questions add **Operate** (SLOs, upgrades, DR, cost). Always name what you would measure.
